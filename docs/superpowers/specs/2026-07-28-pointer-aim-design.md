# 点击瞄准设计

## 目标

让玩家在战斗画布内点击或拖动来控制主炮射击方向，形成“点哪里打哪里”的单手操作；不改变既有自动射速、技能自动索敌和十分钟内结算节奏。

## 交互

- 首次操作前，主炮保持既有自动索敌，避免玩家没有理解操作时停火。
- 点击战场后保存瞄准点；之后的主炮弹沿炮口到瞄准点的固定方向直线飞行。
- 按住并拖动时连续更新瞄准点；松手后保留最后方向。
- 点击不会额外生成子弹，射速仍由主炮冷却和局内升级决定。
- 输入只绑定战斗画布；HUD、技能、倍速和升级按钮不会误触瞄准。
- 瞄准点限制在 HUD 下沿与列车防线之间，并限制在逻辑画布宽度内。

## 战斗规则

- 手动主炮弹不追踪、不在目标死亡后转向，越界后回收。
- 使用固定步长线段碰撞，命中本步路径上最先相交的存活敌人，避免高速或倍速下穿透。
- 多炮管围绕同一瞄准方向作轻微扇形散射。
- 主动技能、连锁弹与分裂弹继续使用既有自动索敌。
- 瞄准输入只影响未来发射的主炮弹，保证回放和倍速下的确定性。

## 视觉与无障碍

- 当前瞄准点显示珊瑚红、奶油白双层手绘准星，短线不遮挡敌人主体。
- 普通模式允许轻微呼吸变化；减少动态效果时保持静态。
- 画布辅助说明明确“点击或拖动瞄准”。

## 验收标准

1. 缩放后的移动视口中，点击坐标能正确换算成 390×844 逻辑坐标。
2. 点击右上方后，新主炮弹向右上方直线运动；点击左侧后方向随之改变。
3. 点击不改变开火间隔，也不会触发额外射击。
4. 直线弹在 1×、1.5×、2×、3×模拟速度下均不会穿过相交敌人。
5. HUD 操作不改变瞄准点，场景卸载后不残留事件监听。
6. 自动索敌回退、技能弹道、升级暂停和结算行为保持通过。
