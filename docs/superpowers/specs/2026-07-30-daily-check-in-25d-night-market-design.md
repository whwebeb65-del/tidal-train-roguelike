# 累计签到 2.5D 潮汐夜摊设计

- 日期：2026-07-30
- 项目：project-002-tidal-train-roguelike
- 状态：视觉方向已由用户确认
- 原型基线：B4「2.5D 潮汐夜摊」

## 1. 目标

把车站主页现有的七日签到表格改造成世界观内的“潮汐夜摊”。玩家仍能立刻看懂七份奖励、领取进度和唯一主操作，但界面不再表现为统一圆角卡片组成的后台面板。

本轮只改变签到视图、样式与轻动态，不修改累计签到规则、奖励数值、存档键、领取事件、埋点或日期回拨保护。

## 2. 已确认的视觉方向

- 延续 B 方案的热闹码头夜市氛围。
- 构图保持随性：奖励可以挂在绳上、放在木架或木箱中，不使用七张等宽卡片。
- 复用现有站台天空、地平线、站台、前景和水獭检修员素材，使角色与背景共享同一套绘景。
- 用远景、中景、摊位、角色、前景五个层级形成 2.5D 深度，不将背景硬改成写实三维。
- 使用暖黄、珊瑚红、海沫绿、旧木棕和深海蓝；减少紫色霓虹、玻璃渐变与均匀外发光。
- 奖励图标必须有固定形态和颜色：齿轮、航线徽记、星票分别使用独立的 CSS 实体造型，不使用 Emoji。
- 水獭检修员负责提示今日奖励，让签到属于车站生活场景。

## 3. 信息与交互

顶部保留日期、标题、轮次、累计次数和七日奖励合计，但将它们表现为摊位招牌与便签。

七份奖励继续按第 1—7 日的 DOM 顺序输出：

- 已领取：降低饱和度并盖“已入库”章。
- 今日可领取：使用暖色聚光、`TODAY` 小牌和低频呼吸光。
- 待领取：保持清晰，但亮度低于今日奖励。
- 第 7 日：表现为更宽的压轴木箱。

领取按钮继续使用 `data-action="claim-daily-check-in"`。禁用、同日已领取、本轮完成和设备日期异常的文案与行为保持不变。

## 4. 结构与素材

`DailyCheckInView.ts` 从 `CHIBI_ART` 取得：

- `station.sky`
- `station.horizon`
- `station.platform`
- `station.foreground`
- `otter`

视图新增以下结构类：

- `daily-check-in-stage`：2.5D 场景容器。
- `daily-check-in-layer--sky|horizon|platform|foreground`：景深图层。
- `daily-check-in-stall`：奖励摊位。
- `daily-check-in-shelf`：两条不等分陈列线。
- `daily-check-in-reward-art` 与 `reward-art--gears|route-marks|star-tickets`：货币实体造型。
- `daily-check-in-mascot` 与 `daily-check-in-speech`：角色与提示。

原有 `.daily-check-in-cell` 类继续保留，确保现有状态测试和潜在选择器兼容，但不再表现为统一卡片。

## 5. 动态

持续动态只允许使用 `transform`、`opacity` 与 `filter`：

- 天空和地平线以不同方向缓慢移动 2—4 px。
- 站台层缓慢移动不超过 5 px。
- 灯泡独立摇摆 3—6 度，周期错开。
- 水獭上下起伏不超过 5 px。
- 今日奖励约每 2.8—3.2 秒呼吸一次。

`prefers-reduced-motion: reduce` 下全部持续动态关闭。动态不能改变 DOM 状态、领取判定或点击区域。

## 6. 响应式与可访问性

- 桌面端摊位与角色并列，七份奖励使用 4+3 的不规则陈列。
- 760px 以下改为两列奖励，第 7 日横跨两列；角色缩小并移到操作区上方。
- 360px 宽度不得横向溢出，按钮保持整行可点击。
- 装饰图层使用空 `alt`，水獭使用描述性 `alt`。
- 领取按钮仍是原生 `button`，禁用态继续使用 `disabled`。
- 文字对比度不得依赖背景图；所有关键信息必须有深色底或文字阴影。

## 7. 性能与降级

- 不新增图片资产；只复用已进入构建产物的 `CHIBI_ART`。
- 场景使用 `contain: layout paint` 和 `isolation: isolate`。
- 前景只在宽屏显示；移动端隐藏前景层以降低遮挡和合成成本。
- 单个素材加载失败时，CSS 背景色仍需保持文字与按钮可读。

## 8. 验收

自动测试应验证：

- 视图仍输出七个 `.daily-check-in-cell`。
- 视图输出五个景深/角色素材 URL。
- 每份奖励有独立货币造型类，不再依赖 Emoji。
- 已领取、今日、待领取和压轴状态仍正确。
- 原领取按钮动作和禁用行为不变。

发布前运行：

- `npm test`
- `npm run typecheck`
- `npm run check:assets`
- `npm run build`
- `npm run smoke:browser`
- `git diff --check`

浏览器验收覆盖桌面和 360px 移动端，并分别检查正常动态与 `prefers-reduced-motion`。

## 9. 非目标

- 不修改签到奖励、签到周期或补签规则。
- 不新增音效、角色配音或领奖粒子爆发。
- 不重绘水獭或站台图片。
- 不把概念稿作为单张不可拆分背景图。
- 不顺带改造每日试炼、商店、军团或其他系统卡片。
