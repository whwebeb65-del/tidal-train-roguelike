# 战斗电台短讯与补给入口设计

## 目标

把战斗中的全局纸张公告改成不遮挡战场的列车电台短讯，并统一激励广告入口的世界观表达。玩家仍能清楚知道操作会播放补给短片；所有广告 placement、可用次数、奖励、失败恢复、遥测与经济数值保持不变。

## 现状与问题

- `AppShell` 的同一张纸张公告同时服务车站和战斗。战斗时它固定在技能区上方，宽度接近整个手机屏幕，最长停留 4.2 秒，会遮住弹道、敌人和技能标签。
- `BattleHUD` 直接显示“广告刷新技能”“看广告刷新三选一”等系统术语，和手绘列车世界观割裂。
- 现有恢复与刷新逻辑已经具备幂等、失败不消耗次数和 placement 遥测，视觉优化不应改动这些成熟约束。

## 方案选择

### 方案 A：仅缩小纸张公告

改动最小，但仍像网页 toast，无法形成战斗专属视觉语言。

### 方案 B：战斗电台短讯（采用）

车站继续使用纸张公告；战斗态通过现有 `.app-shell--battle` 自动切换为窄电台条。奖励入口使用“补给短片”世界观文案，并在 `aria-label` 中明确“激励广告”。不新增付费货币，不改平台接口。

### 方案 C：移除广告并改为局内资源

更接近买断游戏，但会同时改变复活、技能刷新、构筑重抽和重复通关奖励，超出本轮视觉可读性范围。

## 视觉与交互

### 战斗电台短讯

- 位置：手机与桌面均贴战场左下侧，位于技能栏上方但不覆盖技能按钮；最大宽度 236px，最大高度约 46px。
- 构图：深海蓝半透明底、暖金描边、左侧小型 `RADIO` 信号章和两道波纹刻线；不再使用大面积白纸、圆形“潮”印章或封箱胶带。
- 文本：最多两行，超长内容截断；保留 `role="status"` 和 `aria-atomic="true"`。
- 时序：车站公告继续显示 4200ms；战斗短讯显示 2400ms。新消息到达时仍取消旧计时并重新计时。
- 层级：暂停、升级、失败、结算和新手教程打开时继续隐藏；不得遮挡 Boss 船长标题或交互领取卡。
- 动效：普通模式从左侧滑入并轻微闪烁一次；减少动态模式只切换透明度，不发生位移或循环动画。

### 激励入口文案

可见按钮统一使用短片补给语气：

- 技能刷新：`补给短片 · 重整技能`
- 构筑重抽：`补给短片 · 重开货箱`
- 失败复活：`救援短片 · 紧急修复`
- 重复通关双倍：`补给短片 · 双倍托运`

每个按钮的 `aria-label` 明确包含“观看激励广告”，避免用世界观文案掩盖真实行为。完成、取消和失败通知统一写成“补给短片播放完成 / 已退出补给短片 / 补给短片暂时无法播放”，但保留原有结果分支。

## 架构与数据流

- `AppShell.setBattleChrome(active)` 继续作为唯一战斗态来源，不新增运行时 hook。
- `AppShell.setNotice(message)` 根据根节点当前是否为 `.app-shell--battle` 选择 2400ms 或 4200ms；消息内容、DOM 节点和无障碍语义不变。
- `app-shell-v2.css` 负责把同一 notice 节点在战斗态重绘为电台条。车站样式不受影响。
- `BattleHUD.renderBattleHudShell()` 只改变四个按钮的可见文案与 `aria-label`。回调、hidden 状态和 `data-battle-action` 保持原样。
- `LegacyGameRuntime` 只改变玩家可见的广告结果通知；`MockAds`、`RewardedPlacement`、recovery state、次数与 telemetry event 保持原样。

## 异常与兼容

- 广告取消或失败仍不消耗机会；按钮恢复可用。
- 若短讯内容为空，立即隐藏且不启动计时器。
- 如果从车站切入战斗后才设置消息，使用 2400ms；从战斗返回车站后的新消息使用 4200ms。
- 360px 宽度下电台条必须和三个技能按钮、刷新入口保持物理间隔；安全区 inset 仍生效。

## 验证

- `AppShell` 使用 fake timers 验证车站 4199ms 可见、4200ms 隐藏；战斗 2399ms 可见、2400ms 隐藏；新消息重置计时。
- `BattleHUD` DOM 测试验证四个可见文案、四个明确的激励广告 `aria-label`、原 `data-battle-action` 与 hidden 规则。
- `LegacyGameRuntime` 既有广告完成/取消/失败测试继续验证 placement、次数与奖励；新增可见通知文案断言。
- CSS/源码契约验证战斗电台的宽高、位置、两行限制、overlay/tutorial 隐藏和 reduced-motion 分支，并禁止战斗按钮重新出现裸文案 `广告刷新技能`。
- 真实 Chrome 在 360×800、390×844、412×915、430×932 验证无横向溢出、按钮可点击、通知不覆盖技能和交互卡；保留两局胜利、Boss 证据和普通 URL 隔离。

## 非目标

- 不移除广告 SDK 或 placement。
- 不改变复活血量、冷却清零、重抽次数、双倍奖励或任何经济数值。
- 不重做暂停、升级、失败和结算面板。
- 不新增新的永久养成、付费资源或服务端状态。
