# 正式版玩法增强包设计

## 1. 目标与边界

本增强包把当前可玩的战斗竖切继续推进到“有明确操作价值、成长质变、动态声画和四条可复玩航线”的正式试玩水平。范围固定为六项：三种潮兽独立美术、Boss 精准弱点、十分钟节奏重排、技能进化保底、动态战斗音乐、四地图差异化内容。

本轮不接入真实支付、联网排行榜、赛季后台或新的存档大版本；继续使用现有 Web MVP、Mock 平台、固定步长模拟和 GitHub Pages 发布链路。

## 2. 方案比较与选择

### 方案 A：只做表现强化

优点是风险低；缺点是手动瞄准、技能成长和复玩内容仍然没有结构性变化，不能解决当前最明显的产品差距。

### 方案 B：中等规模纵向增强（采用）

在现有战斗引擎边界内新增独立资源、纯规则弱点系统、节奏分段、进化保底、音乐强度和地图战斗档案。它能覆盖六项需求，同时复用既有三技能、四地图、Boss 和存档结构，风险与收益最平衡。

### 方案 C：重做为多章节赛季系统

内容上限最高，但需要服务端权威存档、活动后台、更多 Boss 和大量正式资源，不适合本轮 Web 试玩版。

## 3. 独立潮兽美术

- 为 `tide-shell-hatchling`、`lantern-ray`、`tide-parasite-snail` 各提供一张独立透明 WebP。
- 统一为现有 2.5D Q 版海洋机械生物风格，轮廓分别强调侧向蟹钳、悬浮翼鳐、螺旋背壳。
- 资源进入 `BattleArtCatalog`，由 `BattleRenderer` 按敌人类型直接选图；缺图时仍保留现有 Canvas 轮廓附件作为降级。
- 三张新增资源合计目标不超过 360KB，资产预算脚本必须覆盖。

## 4. 精准弱点系统

- 新建纯函数 `BossWeakPointSystem`，根据 Boss 坐标和行为状态返回弱点圆形区域。
- 只有 `manual` 主炮弹道与开放弱点圆相交时触发精准命中；自动炮、技能和擦过 Boss 身体的手动弹只造成普通伤害。
- 精准命中造成 1.75 倍伤害并返还 4 点潮汐能量，发出独立事件、特效和音效。
- 弱点关闭、Boss 死亡、暂停或升级选择时不产生精准奖励。
- 点击弱点时瞄准标记锁定到弱点中心，画面显示收缩环和“精准破潮”反馈。

## 5. 十分钟节奏

将六个连续密集波次改为九个节拍段：教学、追踪、喘息、远程压迫、支援解题、喘息、混编高压、精英、Boss。普通出怪仍在 345 秒前结束，精英约 330 秒出现，Boss 在 360 秒进入，最迟 600 秒结算。

每个战斗段声明开始、结束、威胁等级和编成，段间保留 4–7 秒无新出怪窗口。确定性调度只使用种子和模拟时间；倍速改变执行速度，不改变出怪顺序或结果。

## 6. 技能进化保底

- 每个技能精通 1 级即开放首个进化，5、10、15 级依次开放其余三个永久进化。
- 单局 Lv.5、Lv.10、Lv.15、Lv.20 为进化节点：如果仍有合法进化，三选一至少出现一个技能进化。
- 每个技能仍最多携带两个进化，保留现有 12 个进化效果和 Rank 规则。
- 新玩家一开始即可获得三种基础质变候选；长期精通逐步扩充进化池，而不是单纯增加数值。
- UI 在保底节点显示“技能进化”缎带和效果关键词。

## 7. 动态程序化音乐

- 新建纯函数 `BattleMusicDirector`，由当前波次、场上威胁、精英/Boss 状态和列车低血量计算 `calm / drive / danger / climax` 四级强度。
- `ProceduralScore` 在不重置小节的前提下调整 BPM、低频、打击层和高音脉冲；Boss 仍使用独立主题，但内部也随阶段升压。
- 强度变化以最短 2 秒滞回避免频繁跳动；暂停冻结音乐时钟，恢复后从当前强度继续。
- 关闭音乐时不调度音符，音效开关继续独立工作。

## 8. 四地图差异化内容

新增 `MapCombatProfile`，让现有四条航线拥有不同的确定性战斗档案：

- 漂流郊区：标准教学编成，所有倍率为 1。
- 旧港口：近战数量更高、敌速 +8%，精英暴露时间更长，强调追踪与爆发。
- 玻璃城：灯笼鳐和针水母权重更高，弱点奖励 +20%，强调精准射击。
- 深海隧道：寄潮螺和礁蟹权重更高、Boss 生命 +18%、潮汐预警更短，强调构筑完成度。

地图档案只改变敌方编成、规则倍率和音乐压力，不新增货币。既有车站等级解锁、首通奖励和存档字段继续使用。

## 9. 架构与数据流

- `WaveScheduler` 读取地图档案并生成节拍化出怪表。
- `BattleEngine` 仍是唯一权威状态，应用地图倍率、弱点判定与进化选择。
- `BossWeakPointSystem`、`BattleMusicDirector` 和 `MapCombatProfiles` 均为无副作用纯模块。
- `BattleRenderer`、`EffectSystem`、`AudioManager` 只消费状态和事件，不自行决定伤害或奖励。
- 图像缺失、音频不可用、降低动态效果和低画质均不得改变战斗结果。

## 10. 验收标准

- 三种新潮兽无需文字或光圈即可凭轮廓区分，资源缺失时降级仍可玩。
- 手动弹命中开放弱点才获得 1.75 倍伤害和 4 能量；自动弹与技能不获得精准奖励。
- 每局存在至少两个明确喘息窗口，1× 正常发挥在十分钟内结束，四档倍速结果等价。
- Lv.5/10/15/20 合法时必含进化候选，新账号具备三个基础进化来源。
- 音乐强度可从 calm 连续升至 climax，切换不重置战斗小节。
- 四地图生成的编成或倍率至少一项不同，重复种子仍确定。
- 360、390、412、430 视口完整 smoke 通过；无横向溢出、HUD 遮挡和测试开关泄漏。
- `npm test`、`npm run typecheck`、`npm run check:assets`、`npm run build`、`npm run smoke:browser`、`npm audit --audit-level=high`、`git diff --check` 全部通过后才发布。
