# 漂流郊区战斗精品竖切设计

## 1. 目标

把“漂流郊区”做成一条在十分钟内具有清晰教学、阵型变化、精英高潮和三阶段 Boss 的正式战斗竖切。玩家应在前两分钟理解手动瞄准价值，在中段学会选择高威胁目标，并在终局通过识别 Boss 预警与弱点获得胜利。

本轮保留现有 20 级、19 次三选一、技能 Rank/变体、账号成长、体力、倍速、固定步长和结算规则。其他地图继续复用既有配置，不在本轮制作独立美术或关卡机制。

## 2. 成功标准

- 新增三种行为不同的普通敌人：潮壳幼蟹、灯笼鳐、寄潮螺。
- 风暴鳐精英具备可读的冲锋预警、换道和短暂无敌窗口。
- 深海回响 Boss 具备召唤、潮浪航道和狂暴弱点三个阶段。
- 点击或拖动瞄准能明显克制远程敌人、护甲支援单位和 Boss 弱点。
- 暴击、破甲、击杀、精英冲锋、Boss 阶段切换具有互相可区分的画面与音频反馈。
- 1× 正常局仍在十分钟内结束；1.5×、2×、3× 与 1× 保持确定性等价。
- 360、390、412、430 移动视口继续通过完整 smoke；桌面适配不属于本轮。

## 3. 十分钟节奏

### 3.1 波次

- 0:00–2:00：泡鳍怪与潮壳幼蟹。幼蟹每隔一段时间横向换道，教会玩家追踪移动目标。
- 2:00–4:00：加入针水母与灯笼鳐。灯笼鳐停在上半场发射慢速预警弹，迫使玩家优先点杀。
- 4:00–6:00：加入礁蟹与寄潮螺。寄潮螺为附近非 Boss 敌人提供可打破的潮甲，形成后排支援目标。
- 6:00 左右：风暴鳐精英入场。其冲锋前显示航道预警，冲锋结束后短暂暴露。
- 8:00 左右：深海回响 Boss 入场；10:00 维持现有硬上限结算。

### 3.2 Boss 阶段

1. 回响召集：Boss 周期召唤混合潮兽，主体正常受伤。
2. 断潮航道：Boss 在两条危险航道制造潮浪，只留一条安全航道；危险航道预警后对列车造成伤害。
3. 狂暴潮眼：Boss 生命低于 35% 或达到时间门槛后进入狂暴，潮眼弱点周期发光。命中弱点获得额外伤害和能量，错过弱点仍可正常推进，避免软锁。

## 4. 敌人职责与规则

### 4.1 潮壳幼蟹 `tide-shell-hatchling`

- 中低生命、中速。
- 每 1.8–2.4 秒确定性选择相邻航道并横移。
- 横移不瞬移，碰撞与生命条跟随当前位置。
- 价值：训练玩家手动追踪，而非只点固定航道。

### 4.2 灯笼鳐 `lantern-ray`

- 低生命、低速，在 `y=260–320` 的远程线停止前进。
- 每 2.5 秒产生一次“蓄光→发射”事件；预警结束后对列车造成固定伤害。
- 被击杀或破坏蓄力后取消本次射击。
- 价值：形成明确的远程高优先级目标。

### 4.3 寄潮螺 `tide-parasite-snail`

- 中等生命、低速。
- 每 2 秒刷新附近同航道、非 Boss 敌人的临时潮甲；每个目标同时只接受一层。
- 寄潮螺死亡时不立即移除已经发放的剩余潮甲，但不再续盾。
- 价值：让玩家先打支援单位，再处理前排。

### 4.4 风暴鳐精英

- 保留现有生命与奖励。
- 冲锋状态拆为预警、冲锋、暴露三个阶段。
- 预警时航道出现高对比箭头；冲锋期间短暂无敌；结束后 1.2 秒承受额外 25% 伤害。
- 换道与冲锋由种子和模拟时间决定，不使用墙钟时间。

## 5. 架构

### 5.1 规则边界

- `BattleTypes.ts` 声明新增敌人种类、敌人行为状态和新的战斗事件。
- `BattleConfig.ts` 保存生命、速度、伤害、经验和行为参数，不把数值散落在渲染器。
- 新建 `EnemyBehaviourSystem.ts`，以纯函数计算普通敌人/精英/Boss 在给定步长下的行为意图；它不绘制、不播放音频、不写存档。
- `WaveScheduler.ts` 只负责确定性出怪表和节奏。
- `BattleEngine.ts` 应用行为意图、伤害、护盾、弱点倍率和事件，并继续作为唯一权威战斗状态。
- `BattleRenderer.ts`、`EffectSystem.ts` 和 `BattleSoundPort` 仅消费状态与事件做表现。

### 5.2 行为状态

`EnemyState` 增加可选的结构化行为字段，包括当前阶段、阶段剩余时间、目标航道、蓄力进度、弱点是否开放和易伤倍率。字段只保存继续模拟所需的最小状态，不保存 DOM、Canvas 或音频对象。

### 5.3 数据流

固定步长开始时，`BattleEngine` 将敌人快照与模拟时间传给行为系统；行为系统返回移动、发盾、远程攻击、预警、冲锋、召唤和阶段切换意图；引擎按稳定顺序应用意图并生成事件；渲染和音频层在该帧消费事件。相同种子、输入与升级选择必须得到相同意图序列。

## 6. 战斗反馈

- 普通命中：短促白青命中星和轻音，不使用全屏震动。
- 暴击：更大的橙金裂光、粗体伤害数字和一次不超过 45ms 的局部命中停顿表现；规则模拟不暂停。
- 破甲：壳片飞散、蓝盾碎裂音，与普通击杀区分。
- 击杀：按敌人轮廓和职责使用不同爆裂形状；连续击杀合并低价值音效，防止音频拥塞。
- 精英冲锋：航道箭头、低频上扬警报、冲锋拖尾和结束后的易伤闪光。
- Boss 阶段：阶段标题只显示一次；潮浪预警不遮挡顶部 HUD 和底部技能；降低动态效果时改用静态危险航道与明暗切换。
- 弱点命中：潮眼收缩、金白环和独立音高，让玩家不看数字也能确认命中正确位置。

## 7. 美术与资源策略

第一批优先使用现有怪物资源的分层变体、色相与附加部件组合，避免一次引入大批未经统一的生成素材。三个新敌人必须有不同外轮廓；若正式独立资源尚未完成，运行时回退仍需通过轮廓附件、主色和行为预警区分，禁止只换名字。

新增运行时资源总预算不超过 450KB；所有图片缺失时战斗规则、点击目标和预警区域仍正常工作。

## 8. 异常与降级

- 远程射击目标已死亡：取消蓄力，不转移为无来源伤害。
- 支援护盾目标已死亡或离场：忽略该意图。
- 航道预警与升级/暂停重叠：模拟保持暂停，恢复后继续剩余预警时间。
- Boss 阶段在同一帧满足多个条件：按召集、航道、狂暴的单向顺序最多前进一步。
- 低性能模式减少拖尾、碎片和伤害数字数量，但保留所有危险预警和弱点反馈。
- 减少动态效果关闭循环摇摆、缩放和震屏，保留颜色、轮廓、文案与静态方向提示。

## 9. 测试与验收

### 9.1 自动测试

- 新敌人配置完整，经验量仍支持正常样本达到 Lv.20。
- 相同种子产生相同换道、蓄力、发盾、冲锋、召唤和 Boss 阶段序列。
- 灯笼鳐在预警结束前死亡不会伤害列车。
- 寄潮螺只给合法目标一层护盾，死亡后不再刷新。
- 精英冲锋无敌和结束易伤倍率在边界帧正确。
- Boss 三阶段单向切换，安全航道始终唯一，弱点倍率只在开放期生效。
- 暂停、升级、广告和页面不可见不会消耗行为计时。
- 四档倍速产生等价结果，硬上限不超过十分钟。
- 新事件映射到不同效果和音效，降低动态效果仍保留危险提示。

### 9.2 浏览器验收

- 360、390、412、430 完整跑通两局；无横向溢出、无 HUD/技能遮挡。
- 三种新普通敌人在 390×844 截图中仅看轮廓即可区分。
- 精英冲锋、Boss 航道和弱点状态均有可读预警。
- 手动点击高优先级目标时，弹道方向和命中反馈与点击位置一致。
- 低画质与减少动态效果下仍能判断危险航道与弱点。

## 10. 发布约束

发布前必须通过 `npm test`、`npm run typecheck`、`npm run check:assets`、`npm run build`、`npm run smoke:browser`、`npm audit --audit-level=high` 和 `git diff --check`。设计、代码和测试分别形成清晰提交，并推送到 GitHub `main`，由 Pages 工作流完成部署。
