# 点击瞄准实现计划

## Task 1：规则层与弹道

- 在战斗帧中增加只读瞄准点，在主炮弹中区分自动追踪与手动直线弹。
- 先增加引擎测试：范围裁剪、固定方向、最近交点、未命中越界回收、自动回退、射速不变。
- 实现主炮瞄准 API、扇形方向和固定步长线段碰撞。
- 运行引擎聚焦测试、全量单测和类型检查。

## Task 2：场景输入与准星

- 先增加场景测试：点击坐标换算、拖动更新、松手保留、卸载清理。
- 在画布上接入 Pointer Events 和指针捕获，不把 HUD 事件传入战斗瞄准。
- 先增加渲染测试，再绘制手绘双层准星并补充触控样式和辅助说明。
- 运行场景与渲染聚焦测试、全量单测、类型检查、资源检查和构建。

## Task 3：发布级验证

- 在真实移动视口执行点击、拖动、技能按钮、倍速与横向溢出检查。
- 运行完整发布门禁和整分支审查。
- 将结果追加到 SDD 进度台账。
